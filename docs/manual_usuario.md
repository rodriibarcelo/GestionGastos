# 6. Manual de usuario (GUI)

> **Importante:** este manual incluye referencias a capturas. Todas estas están guardadas en `docs/imágenes/`.

## 6.1. Inicio (Login)
1. Abre la aplicación.
2. Introduce **usuario** y **contraseña**.
3. Pulsa **Iniciar sesión**.


![](imágenes/login.png)

## 6.2. Registro de usuario
1. Desde la pantalla de login, pulsa **Registrarse**.
2. Completa los datos solicitados y acepta.


![](imágenes/registro1.png)
![](imágenes/registro2.png)

## 6.3. Pantalla principal
Desde la vista principal puedes:
- Registrar gastos personales
- Acceder a categorías
- Acceder a cuentas compartidas
- Ver estadísticas, calendario, alertas e importar gastos

![](imágenes/main.png)

## 6.4. Registrar gasto personal
1. Rellena un **Nuevo gasto**.
2. Introduce cantidad, fecha y categoría.
3. (Opcional) añade una nota.
4. Pulsa **Añadir**.


![](imágenes/gasto_form.png)

## 6.5. Filtrar gastos
1. Abre el diálogo de filtros.
2. Selecciona meses y/o intervalo de fechas y/o categorías.
3. Aplica el filtro para actualizar lista y gráficas.



![](imágenes/filtros.png)

## 6.6. Categorías
1. Entra en **Categorías**.
2. Crea, edita o elimina categorías según tus necesidades.


![](imágenes/categorias1.png)
![](imágenes/categorias2.png)

## 6.7. Cuentas compartidas
### Crear cuenta
1. Entra en **Cuentas compartidas** → **Nueva cuenta**.
2. Introduce el nombre y la lista de participantes.
3. Elige reparto equitativo o por porcentajes (si aplica).
4. Guarda la cuenta.


![](imágenes/cuenta_form1.png)
![](imágenes/cuenta_form2.png)

### Registrar gasto compartido
1. Selecciona una cuenta.
2. Registra un gasto indicando **quién lo pagó**.
3. Revisa los **saldos** actualizados.

![](imágenes/saldos.png)

## 6.8. Estadísticas
Accede a **Estadísticas** para ver gráficas por categorías (barras/circular).  
Los filtros afectan a la información mostrada.


![](imágenes/estadisticas1.png)
![](imágenes/estadisticas2.png)
![](imágenes/estadisticas3.png)
![](imágenes/estadisticas4.png)

## 6.9. Calendario (CalendarFX)
Accede a **Calendario** para ver los gastos como eventos en el día correspondiente.


![](imágenes/calendario.png)

## 6.10. Alertas y notificaciones
1. Configura alertas semanales/mensuales (y opcionalmente por categoría).
2. Cuando se supera un límite, se crea una notificación.
3. Consulta el **historial** de notificaciones.


![](imágenes/alertas1.png)  
![](imágenes/alertas2.png)  
![](imágenes/notificacion.png)

## 6.11. Importación de gastos
1. Entra en **Importar gastos**.
2. Selecciona el fichero y el tipo/formato.
3. Ejecuta la importación.


![](imágenes/importar.png)
