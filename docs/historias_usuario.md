# Historias de Usuario para "Gestión de Gastos y Cuentas Compartidas"

Historia de Usuario 1: Registrar gasto

* Como usuario,
* quiero registrar un gasto con cantidad y fecha y asignarlo a una categoría,
* para llevar el control de mis gastos personales.

Historia de Usuario 2: Editar o borrar gasto

* Como usuario,
* quiero poder editar o borrar un gasto existente,
* para corregir errores o mantener mi historial actualizado.

Historia de Usuario 3: Gestionar categorías

* Como usuario,
* quiero organizar los gastos en categorías predefinidas y poder crear nuevas,
* para adaptar la clasificación a mis necesidades.

Historia de Usuario 4: Listar y filtrar gastos

* Como usuario,
* quiero filtrar los gastos por meses, intervalos de fechas, categorías o combinaciones de estos,
* para analizar la información de forma precisa.

Historia de Usuario 5: Ver información en tabla y gráficos

* Como usuario,
* quiero consultar los gastos en tabla/lista y en gráficos de barras y/o circulares,
* para comprender la distribución por categorías.

Historia de Usuario 6: Configurar alertas por periodo

* Como usuario,
* quiero configurar alertas con umbral semanal o mensual,
* para recibir avisos cuando supere el límite de gasto.

Historia de Usuario 7: Alertas por categoría

* Como usuario,
* quiero que una alerta pueda vincularse a una categoría específica,
* para controlar partidas concretas.

Historia de Usuario 8: Recibir y revisar notificaciones

* Como usuario,
* quiero recibir una notificación cuando se dispare una alerta y poder consultar el historial,
* para revisar avisos pasados en cualquier momento.

Historia de Usuario 9: Crear cuenta de gasto compartida

* Como usuario,
* quiero crear una cuenta de gasto compartida con una lista fija de personas,
* para gestionar gastos comunes con otros.

Historia de Usuario 10: Registrar gasto en cuenta compartida

* Como usuario,
* quiero registrar un gasto dentro de una cuenta indicando quién lo pagó,
* para que el sistema reparta el importe y actualice el saldo de cada persona.

Historia de Usuario 11: Definir reparto equitativo o porcentual

* Como usuario,
* quiero que la cuenta compartida pueda repartir equitativamente o por porcentajes que sumen 100%,
* para reflejar cómo asumimos los gastos en el grupo.

Historia de Usuario 12: Consultar saldos en la cuenta compartida

* Como usuario,
* quiero ver el saldo (positivo/negativo) de cada persona en la cuenta,
* para saber quién debe a quién y cuánto.

Historia de Usuario 13: Importar gastos desde fichero

* Como usuario,
* quiero importar gastos desde un fichero de texto y soportar distintos formatos,
* para incorporar datos externos sin introducirlos manualmente.

Historia de Usuario 14: Usar línea de comandos

* Como usuario,
* quiero registrar, modificar y borrar gastos desde una línea de comandos básica,
* para poder gestionar gastos también sin interfaz gráfica.
